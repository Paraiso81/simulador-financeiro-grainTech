# Calculadora de Prazo Crítico para Negociação do grão

## Requisitos:

O programa deve exibir a cotação média dos principais grãos armazenados em silos

Inputs:
Perguntar quantas toneladas de grão entram no silo diariamente:
Perguntar quantas toneladas de grão saem do silo diariamente:
Perguntar o volume/quantidade atual armazenada no silo.
Perguntar a capacidade máxima do silo:

Fazer o calculo para prever em quantos dias o Silo vai estar com capacidade máxima

exibir ao usuário:
Valores das cotações
tempo estimado de lotação do silo
valor atual da quantidade que ele tem armazenado
valor previsto que ele vai ter ao silo ficar com capacidade máxima

valores de referência 
soja: 120.50, 
milho: 60.00, 
arroz: 105.00
